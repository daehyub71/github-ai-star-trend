1. **후보군이 가정(2만 개)보다 훨씬 크다.** 스타 1,000개 이상 6.6만 개, 500개 이상 12.5만 개, 100개 이상 48.6만 개.

3. **우리 후보 규칙은 Trending 주간 목록을 100% 포함한다** (14개 모두 시작 시점 8,500 스타 이상). API 주간 값과 Trending 의 "이번 주" 값도 거의 같다 — 데이터는 믿을 만하다.

5. **히스토리 API 는 하루 단위로 하루 늦게 반영된다.** 주 경계는 UTC 일요일 0시(KST 일요일 09시). 주간 실행은 **월요일 00:00 UTC(09:00 KST)** 이후가 안전하다.

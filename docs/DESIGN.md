## 4. 시안에 쓴 데이터

- 숫자는 **2026-10-26 실측 표본**(`docs/MEASURE.md`)이다. GitHub 전체를 집계한 랭킹이 아니다 — 화면 위쪽 띠에 밝혔다.
  - 지금 뜨는 / 규모 대비: Trending 14개와 새 저장소 표본의 실제 지난 주 값(2026-10-18 주)
  - 새로 뜨는: 생성 30일 이내·스타 50 이상 검색 결과 상위(실제 값)
  - 누적 TOP: 스타 5만 이상 521개 전체 목록 상위(실제 값)
  - 카드: cloudflare/security-audit-skill 의 실제 일별 스타 5주치·포크·이슈·생성일
- **카테고리는 분류 예시**다(Phase 2 에서 LLM 이 판정). AI 탭의 빈 칸은 `[분류 후 채워짐]`.
- 카테고리 추이 그래프의 **곡선은 모양 예시**다 — 실제 값이 아니고, 세로축에 숫자를 넣지 않았다.
- 근거가 필요한 문장(계기 사건·README 분석·비교·활용사례)은 `[ ]` 자리표시다.
